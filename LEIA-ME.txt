DEVSTUDIO AI - VERSAO 2.0

Esta versão inclui:
- Editor Dart próprio com numeração de linhas e realce básico de sintaxe.
- Salvamento automático no armazenamento local do navegador.
- Botão para baixar o arquivo .dart.
- Atalho para abrir o DartPad oficial como ambiente de execução online.
- Service worker e manifesto PWA.

IMPORTANTE:
O editor local ainda não compila projetos Dart/Flutter. Para executar Dart, use o DartPad incorporado, com internet. O salvamento local fica no navegador/aparelho atual; use "Baixar .dart" para criar uma cópia de segurança.

PUBLICAÇÃO:
Envie/substitua os arquivos da raiz do repositório GitHub Pages e mantenha a pasta icons com os dois PNGs.
Depois do commit, aguarde a publicação e atualize o site. Se o navegador mostrar a versão antiga, feche a aba e abra novamente ou limpe os dados/cache do site.
