DEVSTUDIO AI - VERSAO 3.0

Novidades:
- Criar, listar, abrir, renomear e excluir projetos.
- Criar e renomear arquivos dentro do projeto.
- Editor Dart com numeração de linhas e realce básico.
- Salvamento automático no navegador.
- Exportar projeto em JSON e importar arquivos Dart/TXT ou projetos JSON.
- Baixar arquivo Dart atual e abrir DartPad.

LIMITACOES:
Os projetos ficam no armazenamento local deste navegador/aparelho, não na nuvem. Limpar os dados do navegador pode apagar os projetos. Use Exportar projeto para guardar cópia.
O editor ainda não compila projetos Flutter completos. Para executar Dart, use DartPad com internet.

PUBLICACAO:
Substitua os arquivos da raiz do GitHub Pages. Mantenha icons/icon-192.png e icons/icon-512.png dentro da pasta icons.
